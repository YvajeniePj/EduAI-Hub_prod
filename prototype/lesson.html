Условные операторы if/else

Что такое условные операторы?

Условные операторы — это фундаментальная конструкция в любом языке программирования, которая позволяет программе принимать решения и выполнять различные блоки кода в зависимости от того, истинно или ложно определённое условие. В Python условные операторы реализуются с помощью ключевых слов if, elif и else.

Благодаря условным операторам программа может реагировать на различные входные данные и ситуации, делая код гибким и интерактивным. Например, вы можете проверить, является ли пользователь авторизованным, достаточно ли средств на счёте или корректны ли введённые данные.

Синтаксис if/else

Базовый синтаксис условного оператора в Python выглядит следующим образом. Обратите внимание, что в Python отступы (обычно 4 пробела) определяют, какой блок кода относится к какому условию: 

age = 18

if age >= 18:
    print("Вы совершеннолетний")
    print("Доступ разрешён")
else:
    print("Вы несовершеннолетний")
    print("Доступ ограничен")

В этом примере переменная age проверяется на условие age >= 18. Если условие истинно, выполняется первый блок кода (после if). Если условие ложно — выполняется блок после else.

Оператор elif

Когда нужно проверить несколько условий последовательно, используется ключевое слово elif (сокращение от «else if»). Это позволяет создавать цепочки проверок без глубокой вложенности кода: 

score = 85

if score >= 90:
    grade = "Отлично"
elif score >= 75:
    grade = "Хорошо"
elif score >= 60:
    grade = "Удовлетворительно"
else:
    grade = "Неудовлетворительно"

print(f"Ваша оценка: {grade}")
# Вывод: Ваша оценка: Хорошо

Python проверяет условия сверху вниз и выполняет блок кода для первого истинного условия. Остальные блоки elif и else пропускаются. Если ни одно из условий не выполняется, выполняется блок else (если он указан).

Практические советы

  • Избегайте глубокой вложенности: Если у вас больше 3 уровней вложенных if, подумайте о рефакторинге — выделите логику в отдельные функции или используйте elif.
  • Используйте тернарный оператор для простых случаев: Вместо многострочного if/else можно написать result = "да" if condition else "нет".
  • Проверяйте граничные значения: При написании условий убедитесь, что все возможные значения обработаны, включая крайние случаи (например, 0, пустую строку, None).
  • Помните о порядке условий: Ставьте более специфичные условия выше, а более общие — ниже. Это поможет избежать логических ошибок.
