# EduAI Hub — Инновационная платформа для эффективного обучения

## Аннотация

EduAI Hub представляет собой современную экосистему электронного обучения, интегрированную с передовыми технологиями искусственного интеллекта. Платформа разработана как комплексный ответ на вызовы современной цифровой эпохи в образовании, объединяя в себе классические функции систем управления обучением (LMS) с интеллектуальным авто-грейдингом, AI-ассистированием, а также развитыми механиками взаимного оценивания (Peer Review) и геймификации. Основная цель проекта — создание бесшовной, мотивирующей и высокотехнологичной среды для получения знаний.

Система ориентирована на студентов, преподавателей и администраторов образовательных программ. EduAI Hub централизует разрозненные учебные материалы (лекционные презентации, видеозаписи, текстовые документы, тесты), организуя их в понятные интерактивные учебные модули. Благодаря этому каждый участник процесса получает единую точку доступа ко всей образовательной траектории курса.

Ключевой особенностью платформы является встроенный умный AI-ассистент. Он функционирует на базе современных больших языковых моделей (LLM) и доступен для учащихся в режиме 24/7. Ассистент способен отвечать на сложные вопросы по содержанию лекций, напоминать о приближающихся дедлайнах и предлагать релевантные дополнительные материалы для изучения. Это полностью решает проблему ожидания ответов от преподавателей студентами, находящимися в разных часовых поясах.

Для преподавательского состава EduAI Hub предлагает мощные инструменты автоматизации. Модуль авто-грейдинга позволяет мгновенно проверять решения тестов и открытых заданий с автоматическим формированием детального качественного фидбека для каждого студента. Наряду с этим, система взаимной проверки (Peer Review) органично распределяет анонимные работы сокурсников для перекрестного оценивания, что не только снижает нагрузку на проверяющих, но и развивает аналитическое мышление у самих учащихся.

Социальное взаимодействие и мотивация студентов поддерживаются за счет встроенного p2p-чата и модуля геймификации. Прямое общение между студентами и преподавателями внутри платформы снижает чувство изоляции, характерное для дистанционного обучения. Геймификация, выраженная через рейтинговые таблицы (лидерборды) и начисление баллов за активность, стимулирует здоровую конкуренцию и способствует более глубокому погружению студентов в учебный процесс.

EduAI Hub переводит электронное образование на уровень автономии, при котором рутинные операции автоматизированы, а преподаватели могут сфокусироваться на индивидуальном наставничестве и развитии качества контента, обеспечивая студентам максимальную поддержку на протяжении всего пути обучения.

## Проблематика

Традиционное образование сегодня часто не успевает за цифровой эпохой, порождая ряд системных проблем:
1. **Рутинные проверки и задержка обратной связи:** Преподаватели тратят десятки часов в неделю на ручную проверку однотипных работ, из-за чего студенты вынуждены долго ждать фидбек, теряя контекст выполнения задания.
2. **Асинхронность и часовые пояса:** Студенты современных распределенных программ (например, AI Talent Hub) учатся из разных регионов и часовых поясов. Простой вопрос по материалу лекции или организации курса превращается в часы ожидания ответа от преподавателя.
3. **Хаос учебных материалов:** Использование разрозненных каналов (Telegram, Google Drive, LMS, почта) для публикации видео, презентаций и тестов приводит к потере структуры и усложняет поиск нужной информации.
4. **Снижение вовлеченности и мотивации:** Отсутствие интерактивного взаимодействия и игровых элементов приводит к изоляции студентов в онлайн-среде, перегоранию и, как следствие, росту процента отсева с курсов.

## Постановка задачи

Целью проекта является разработка и внедрение интеллектуальной веб-платформы EduAI Hub, решающей проблемы асинхронного обучения и снижения вовлеченности. Для достижения цели необходимо решить следующие задачи:
1. Разработать единый структурированный веб-интерфейс курса, заменяющий разрозненные внешние инструменты.
2. Интегрировать умного ИИ-помощника для круглосуточных ответов на вопросы студентов по материалам курсов.
3. Автоматизировать проверку открытых заданий и генерацию развернутого фидбека с помощью технологий искусственного интеллекта.
4. Создать безопасный механизм взаимной проверки работ (Peer Review) студентами внутри интерфейса заданий.
5. Реализовать p2p-чат для прямой коммуникации участников процесса без использования сторонних мессенджеров.
6. Внедрить систему контроля прогресса на основе реального взаимодействия студента с контентом (видео, PDF, тексты) и модуль геймификации.

## Описание технического решения

Платформа EduAI Hub построена по современной микросервисной архитектуре, обеспечивающей масштабируемость и отказоустойчивость:
* **Фронтенд:** Разработан на фреймворке **Angular 17+** с использованием библиотек Angular Material для соответствия премиальным гайдлайнам Google Classroom. Архитектура построена на реактивных потоках (`RxJS`) с оптимизацией рендеринга и защитой от дублирования API-запросов.
* **Бэкенд:** Состоит из независимых микросервисов на **FastAPI (Python)**, каждый из которых отвечает за свой домен (тесты, видео, материалы, чат, геймификация, ИИ). Микросервисы взаимодействуют через синхронные HTTP-запросы и асинхронные уведомления.
* **Базы данных:** В качестве основного хранилища используется **PostgreSQL**, для кэширования и быстрых сессий — **Redis**. Реализовано каскадное удаление данных на уровне API Gateway для предотвращения появления осиротевших записей при удалении курсов.
* **AI-интеграция:** Использование API больших языковых моделей (LLM) для авто-грейдинга решений, формирования текстовых рекомендаций и работы интеллектуального ассистента.
* **Безопасность:** Авторизация и единая точка входа (SSO) реализованы через интеграцию с сервером аутентификации **Keycloak (OIDC протокол)**.

## Полученные результаты

В результате реализации проекта были достигнуты следующие ключевые результаты:

1. **Развертывание пилотной версии:** Успешно разработана и развернута демоверсия платформы EduAI Hub на серверных мощностях университета, что подтвердило работоспособность выбранной микросервисной архитектуры в реальном инфраструктурном окружении.
2. **Единая авторизация через Telegram:** Платформа интегрирована с университетской системой авторизации. Пользователи могут мгновенно и безопасно входить в личные кабинеты, используя свои аккаунты в Telegram, что значительно упрощает онбординг и администрирование пользователей.
3. **Объединение образовательных инструментов:** Создана целостная экосистема, заменяющая собой разрозненные внешние сервисы. В рамках единого веб-интерфейса бесшовно объединены видеолекции, база знаний, тесты с автоматической AI-проверкой, p2p-сообщения и система кросс-оценивания (Peer Review).
4. **Готовность к пилотному запуску:** Проведен комплекс работ по оптимизации производительности бэкенда и интерфейса. На текущий момент платформа находится в состоянии полной готовности к запуску масштабного пользовательского тестирования с привлечением академических групп и преподавательского состава.

## Дальнейшие планы по развитию

1. **Интеграция Real-Time WebSockets:** Перевод p2p-чата и трансляций на протокол WebSockets для обеспечения мгновенной доставки сообщений без периодического опроса (polling).
2. **Улучшенные AI-агенты:** Расширение возможностей ИИ-помощника до автономного агента, способного проактивно предлагать студентам помощь при возникновении трудностей с тестами.
3. **Продвинутая аналитика эмоций:** Использование анализа текста сообщений в чатах для выявления признаков выгорания студентов на ранних стадиях.
